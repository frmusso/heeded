# security

heeded reads transcripts that can hold secrets, and sends excerpts of them to your own `claude`. so a way it could leak
one is a security problem: a secret the redaction misses, a file sent that shouldn't be, anything heeded writes outside
its own cache.

report it privately on github: the repository's **security** tab, **report a vulnerability**. please not in a public
issue. fixes go into the next release; only the latest version is supported.
